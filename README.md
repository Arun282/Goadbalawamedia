# Haryana State Zone

Android WebView app for the Haryana State Zone daily news website and e-paper.

- Live website: https://haryana-state-zone.floot.app
- Package: `com.haryanastatezone.news`
- Minimum Android: 7.0 (API 24)
- Build: GitHub Actions → **Build Haryana State Zone APK**
- APK artifact: `HaryanaStateZone-debug-apk`

The workflow builds a debug APK and uploads it as a downloadable Actions artifact. The app loads the live news website, including its daily e-paper page, and supports Android back navigation inside the web view.

This project is developed on the `haryana-state-zone` branch so the original `main` branch for Goad Balawa Media is preserved.
